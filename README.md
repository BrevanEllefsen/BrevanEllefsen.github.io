# BrevanEllefsen.github.io
Personal academic website of Brevan Ellefsen

This is a Quarto website. The editable pages are `index.qmd`, `research.qmd`,
`talks.qmd`, and `cv.qmd`; talk and conference entries are in `talks.yml`.

Run `quarto render` from the repository root to rebuild the site in `docs/`.
The included `docs/` directory is already rendered and ready for GitHub Pages.
Keep GitHub Pages configured to deploy from the `docs/` folder on the `main`
branch, and commit both the source and rendered files when updating the site.

The downloadable CV is `files/cv.pdf`, copied into `docs/files/cv.pdf` during
rendering. Replace that file and render again when updating the CV.

The November 2026 update incorporates the supplied CV, including the Tsinghua,
SIMIS, and Wisconsin invited talks, precise SLMath talk dates, the CIRM program,
teaching totals, fellowship support, and mentoring and seminar organization.
The research page also describes ongoing surface-counting extensions and the
least-weight, volume, and minimal-lamination projects. Earlier talks have been
retained. The Tsinghua title follows the current official seminar announcement.
